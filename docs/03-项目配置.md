## 二、模型服务参数

```bat
llama-server.exe -m D:\ai\mt\models\Qwen3-8B-Q4_K_M.gguf ^
  --alias qwen3-8b --host 127.0.0.1 --port 8080 ^
  -c 12288 --parallel 2 -ngl 99 -fa on ^
  --cache-type-k q8_0 --cache-type-v q8_0 ^
  --jinja --temp 0.2 --top-p 0.8 --top-k 20
```

| 参数 | 值 | 理由 |
|---|---|---|
| `-c 12288` | 总上下文 12K | 每槽 6144，够放系统提示 + 术语表 + 一个网页段落 |
| `--parallel 2` | 2 个并发槽 | 与插件「每秒最大请求数」配合；上下文按槽平分 |
| `-ngl 99` | 全部层上 GPU | 4.7 GB 权重全进显存 |
| `-fa on` | Flash Attention | 省显存 + 提速；**KV 量化依赖它** |
| `--cache-type-k/v q8_0` | KV 量化 | 12K 上下文的 KV 从 ~1.9 GB 压到 ~0.95 GB |
| `--jinja` | 用 GGUF 内嵌模板 | Qwen3 模板必需 |
| `--temp 0.2` 等 | 采样参数 | 网关请求会覆盖；这里只是服务端默认值 |

**显存预算**：权重 4.7 + KV 0.95 + 计算缓冲 0.5 + CUDA 上下文 0.3 ≈ **6.4 GB**（实测 6340 MiB）。

> `--parallel 3` 或 `-c 16384` 会逼近 8 GB 上限；`--parallel 4` 会 OOM。

## 三、网关（`local-mt-gateway.py` v1.1）

### 它做什么

| 功能 | 说明 |
|---|---|
| **代码块隔离** | Markdown 围栏代码块 / `<pre><code>` 整块不进模型，还原时用原文逐字节贴回 |
| **行内标识符保护** | `--flag` / `API_KEY` / `v1.2.3` / `pkg.func()` / URL / 变量 / emoji 一律掩码 |
| **占位符校验** | 模型吞掉标记 → 低温重试 → 仍失败则回退原文（绝不吐坏数据） |
| **漏译检测** | 空输出 / 拒绝 / 过短 / 过长 / 句数骤减 → 重试 |
| **页级术语记忆** | 会话级术语表，后台自动抽取 + 种子术语表 |

### HTTP 端点

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/v1/chat/completions` | 主入口（OpenAI 兼容，支持流式） |
| POST | `/translate` | 沉浸式翻译「自定义接口」备用通道 |
| GET | `/health` | 存活检查 |
| GET | `/glossary` | 查看当前术语表（seed + learned） |
| POST | `/reset` | 清空当前会话术语 |

### 可调参数（文件顶部常量）

| 常量 | 默认 | 含义 |
|---|---|---|
| `TEMP` | 0.2 | 采样温度；要更稳填 0.0 |
| `HARVEST_EVERY` | 50 | 每累计 N 个片段后台抽取一次术语 |
| `HARVEST_KEEP` | 40 | 注入 prompt 的术语上限 |
| `SESSION_IDLE` | 900 | 会话空闲超时（秒），超时后术语记忆清空 |
| `TIMEOUT` | 180.0 | 单次后端请求超时（秒） |

### 已打补丁记录（改代码前必读）

| 编号 | 位置 | 内容 |
|---|---|---|
| **P1** | `backend_text` / `backend_stream` | `httpx.AsyncClient(..., trust_env=False)` —— 绕开系统代理，否则 502 |
| **P2** | `looks_bad` | 中文句末标点（`。！？`）独立计数 + `max(1, s//3)` —— 修复 3 句以上段落被误判为截断 |

**如从旧备份恢复代码，这两处补丁必须重新打。**

## 四、维护手册

### 升级 llama.cpp

```powershell
D:\ai\mt\get-zips.ps1          # 自动查最新版、探测镜像、下载
D:\ai\mt\install-llama.ps1 -Zip "<路径1>","<路径2>"
```

- 只下 **`-cuda-12.4-`** 的包（不要 13.4，驱动只支持到 12.4）
- 需要 `llama-*bin-win-cuda*x64.zip` + `cudart-*bin-win-cuda*x64.zip` **两个**

### 更换模型

改 `start-model.bat` 里的 `-m` 路径即可（`--alias` 建议同步修改，并更新插件里的「模型」字段）。

### 清空术语记忆

```powershell
curl.exe -X POST http://127.0.0.1:8000/reset
```

或换文档后等 900 秒自动过期。

### 查看运行日志

`D:\ai\mt\logs\gateway.log`，关注 `[retry]` / `[fallback]` / `[err]` / `[harvest]` 行。

## 五、已知问题

### 1. GitHub commit 正文不翻译

**原因**：GitHub 把 commit message 正文渲染在 `<pre>` 里，而沉浸式翻译默认跳过 `<pre>`/`<code>`。

**解法（按侵入性递增）**

| 方案 | 做法 | 代价 |
|---|---|---|
| A | 划词翻译 / 悬停翻译 | 每次手动 |
| B | 开发者设置 → Edit User Rules 加站点规则，`excludeTags.remove: ["pre"]` + `stayOriginalSelectors.add` 保护代码块 | 可能误伤 README 代码块，需验证 |
| C | 油猴脚本把 commit 正文的 `<pre>` 换成 `<div>`（代码块仍是 `<pre>`，不受影响） | 需装 Tampermonkey |

### 2. 长段落变英文或插件弹窗

网关 v1.0 的 P2 缺陷。**确认 P2 补丁存在**：

```powershell
Select-String -Path D:\ai\mt\local-mt-gateway.py -Pattern 'o <= max'
```

### 3. 网络限制备忘

| 目标 | 状态 | 对策 |
|---|---|---|
| `api.github.com` | 直连正常 | — |
| `github.com` | 直连超时 | 加速前缀 `https://ghfast.top/` |
| `huggingface.co` | 需镜像 | `HF_ENDPOINT=https://hf-mirror.com` + `HF_HUB_DISABLE_XET=1` |
| 系统/IE 代理 | `127.0.0.1:7993` | 网关必须 `trust_env=False`；PowerShell 的 `Invoke-RestMethod` 会踩这个坑，优先用 `curl.exe` |
