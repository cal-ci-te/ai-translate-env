# 01 · 启动方式

## 前置条件（一次性，已完成）

- 推理引擎：`D:\ai\llama\llama-server.exe`（llama.cpp b10992，win-cuda-12.4）
- 模型：`D:\ai\mt\models\Qwen3-8B-Q4_K_M.gguf`（4.68 GiB，sha256 已校验）
- Python 依赖：`fastapi` / `uvicorn[standard]` / `httpx`（装在 `D:\Python\Python313`）

> ⚠️ **本机有 4 个 Python**。PATH 里的裸 `python` 指向 MSYS2 的 Python 3.14，
> 它**没有 pip、没有依赖**。所有脚本一律使用 `D:\Python\Python313\python.exe` 绝对路径。
> 装包时用：`D:\Python\Python313\python.exe -m pip install 包名`

## 日常启动（三步）

### 第 1 步 · 模型服务

双击 `D:\ai\mt\start-model.bat`

等待日志出现：

```
main: server is listening on http://127.0.0.1:8080
```

- 首次加载 4.7 GB 权重到显存约 **10–30 秒**
- 稳定占用显存约 **6340 MiB**
- 日志中会看到 `n_slots = 2, n_ctx_slot = 6144`

### 第 2 步 · 网关

双击 `D:\ai\mt\start-gateway.bat`

等待日志出现：

```
15:07:29 gateway on http://127.0.0.1:8000  ->  http://127.0.0.1:8080/v1/chat/completions
```

**⚠️ 顺序不能反。** 网关只是转发与加工层，不跑模型；模型服务没起来，网关会报 502。

### 第 3 步 · 使用

浏览器打开英文网页 → 点沉浸式翻译图标 → 翻译。

两个黑窗口**最小化即可，不要关闭**。

## 停止

- 关闭两个黑窗口，或在窗口内按 `Ctrl+C`
- 无后台服务、无开机自启，关窗口即完全停止

```powershell
$json = @'
```

## 启动脚本内容（备份）

**`start-model.bat`**

```bat
@echo off
chcp 65001 >nul
cd /d D:\ai\llama
llama-server.exe -m D:\ai\mt\models\Qwen3-8B-Q4_K_M.gguf --alias qwen3-8b --host 127.0.0.1 --port 8080 -c 12288 --parallel 2 -ngl 99 -fa on --cache-type-k q8_0 --cache-type-v q8_0 --jinja --temp 0.2 --top-p 0.8 --top-k 20
```

**`start-gateway.bat`**

```bat
@echo off
chcp 65001 >nul
set PYTHONUTF8=1
cd /d D:\ai\mt
D:\Python\Python313\python.exe local-mt-gateway.py
echo.
echo [gateway exited] press any key to close
pause >nul
```

## 启动排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 网关报 `502 Bad Gateway` | 被系统/IE 代理（`127.0.0.1:7993`）拦截 | 确认网关里 `httpx.AsyncClient(..., trust_env=False)` 存在 |
| 网关报 `No module named 'fastapi'` | 用了 MSYS2 的 python | bat 里必须写 `D:\Python\Python313\python.exe` 全路径 |
| 双击 bat 一闪而过 | 程序报错，窗口自动关闭 | bat 末尾加 `pause`（现有脚本已含） |
| 缺 `cudart64_12.dll` | cudart 包未解压到同目录 | 检查 `D:\ai\llama` 下的 dll |
| 缺 `VCRUNTIME140.dll` | 缺 VC++ 运行库 | 装 Microsoft Visual C++ 2015–2022 Redistributable (x64) |
| 显存不足 / OOM | 上下文过大 | 把 `-c 12288` 降到 `-c 8192` |
| 启动报 `--version` 失败 | 新版 llama.cpp 已移除该参数 | 无害，用 `--list-devices` 验证即可 |
